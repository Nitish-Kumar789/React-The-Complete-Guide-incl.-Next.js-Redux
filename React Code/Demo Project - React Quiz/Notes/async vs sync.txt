Anything promise-based is async.
Promise
.then()

🟣 3️⃣ API / Network Calls

fetch()
axios.get() (external library)

🟡 4️⃣ React State Updates

setState() (class components)
useState() setter (like setCount())

🟠 5️⃣ React Effects

useEffect() (runs after render)
