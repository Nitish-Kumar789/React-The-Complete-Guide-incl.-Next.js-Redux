map() is an array method

it: 
Loops through each element
Transforms it
Returns a NEW array

Original array stays unchanged.


const numbers = [1, 2, 3];

const doubled = numbers.map((num) => num * 2);

console.log(doubled);

so, conclusion
map will take one array, iterate over elements, do some Transformation on each element and will return new array
