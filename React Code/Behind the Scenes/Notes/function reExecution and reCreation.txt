When component renders:

function Parent() {
  const handleClick = () => {
    console.log("clicked");
  };

  return <button onClick={handleClick}>Click</button>;
}

On every render:

Parent function re-executes.

handleClick function is re-created.

New memory reference is created.

That is why memoized children may re-render.

4️⃣ Simple Difference

Re-execution
= Running the function again.

Re-creation
= Creating a new function object in memory.

5️⃣ Important in React

When state changes:

Component function re-executes.

All functions defined inside are re-created.

State is preserved separately by React.

That is why we use:

useCallback
To prevent re-creation of functions.

Final Simple Understanding

Re-execution = Running
Re-creation = New memory reference

In React, both happen during re-render unless optimized.
